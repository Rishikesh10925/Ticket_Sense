# API Contract v0 (Week 1)

The contract the three workstreams build against (Roadmap R7: "OpenAPI contract in
Week 1"). The machine-readable spec is generated by FastAPI at `GET /openapi.json`
(`make openapi` writes it to `docs/openapi.json`); this page is the human-readable
agreement, including endpoints that do not exist yet.

Status: **live** = implemented today, **planned (Wn)** = agreed shape, built in week n.
All routes except `/health`, `/auth/register` and `/auth/login` need a bearer JWT.

## Auth and users

| Method | Path | Roles | Status | Purpose |
|---|---|---|---|---|
| POST | `/auth/register` | public | live | Create an end-user account |
| POST | `/auth/login` | public | live | Issue a JWT (`sub`, `role`, `exp`) |
| GET | `/auth/me` | any | live | Current user |
| GET, POST, PATCH | `/users`, `/users/{id}` | admin | live | Manage engineers and admins |

## Tickets

| Method | Path | Roles | Status | Purpose |
|---|---|---|---|---|
| POST | `/tickets` | end_user | live | Create; multipart `subject`, `description`, optional `attachment` (.txt/.log in core scope) |
| GET | `/tickets?department=&status=&lane=` | any | live (`lane` planned W9) | List tickets the caller may see |
| GET | `/tickets/{id}` | any | live | Ticket detail (end users never see drafts or evidence) |
| GET | `/tickets/{id}/evidence` | engineer, admin | live | Ranked passages with scores |
| GET | `/tickets/{id}/draft` | engineer, admin | planned (W5) | Structured draft, claims, citations, can-answer flag, per-claim support |
| GET | `/tickets/{id}/decision` | engineer, admin | planned (W8) | Lane, calibrated score, thresholds used, top reasons, model and threshold versions |
| POST | `/tickets/{id}/review` | engineer, admin | planned (W9; replaces `/feedback`) | Accept, edit, reject or escalate, with time taken and reason codes |
| POST | `/tickets/{id}/feedback` | engineer, admin | live (deprecated in W9) | V1 review actions |

### `GET /tickets/{id}/draft` (planned)

```json
{
  "draft_id": "uuid",
  "can_answer": true,
  "steps": [
    {"text": "Restart the VPN client.", "citations": [1],
     "claims": [{"text": "Restart the VPN client", "support": 0.93}]}
  ],
  "missing_information": ["OS version"],
  "groundedness": 0.88,
  "weakest_claims": [{"text": "...", "support": 0.21}],
  "prompt_version": "draft-v1",
  "model": "qwen2.5:7b-instruct"
}
```

### `POST /tickets/{id}/review` (planned)

```json
{
  "action": "accept | edit | reject | escalate",
  "final_reply": "string, required for accept/edit",
  "reason_codes": ["missing_step"],
  "time_taken_ms": 41250
}
```

## Admin

| Method | Path | Roles | Status | Purpose |
|---|---|---|---|---|
| GET | `/departments` | any | live | Departments |
| GET | `/admin/thresholds` | admin | planned (W8) | Current error budgets (alpha fast, alpha assisted, delta), thresholds, version |
| PUT | `/admin/thresholds` | admin | planned (W8) | Set budgets; thresholds recomputed by the Learn-then-Test step; returns expected coverage |

| GET, POST | `/knowledge-base` | admin | live | KB articles |
| GET, POST | `/escalations/...` | admin | live | Escalation approval |

## Annotation (outside reviewers)

| Method | Path | Roles | Status | Purpose |
|---|---|---|---|---|
| GET | `/annotate/next` | annotator | planned (W4) | Next blinded draft: ticket, draft, cited evidence. Never the score, lane or signals |
| POST | `/annotate/{assignment_id}` | annotator | planned (W4) | Label A/M/R/W, reason codes, time taken, rubric version |

`annotator` is a restricted account type for outside reviewers. It is not a fourth
product role: it cannot open tickets, queues or admin screens.

## Conventions

- IDs are UUIDs. Times are ISO 8601 UTC.
- Errors: `{"detail": "message"}` with the matching HTTP status.
- Every pipeline output that a decision depends on carries a version string
  (`prompt_version`, `model_version`, `threshold_version`) so any past decision can be explained.
