# Third-party models, data and licences

What the project uses that it did not write, and under which terms. The repository's own
licence is still to be chosen by the authors (see the README). Licences were recorded on
2026-10-30; check each at its source before a release.

## Models

| Model | Used for | Where in the code | Licence |
|---|---|---|---|
| `sentence-transformers/all-MiniLM-L6-v2` | Embeddings (retrieval, classifier) | `ai/embeddings/` | Apache-2.0 |
| `cross-encoder/ms-marco-MiniLM-L-6-v2` | Reranking the top 20 passages | `ai/retrieval/` | Apache-2.0 |
| `cross-encoder/nli-deberta-v3-base` | Claim support (NLI) | `ai/grounding/claims.py` | Apache-2.0 |
| `qwen2.5:7b-instruct` (Ollama) | Drafting replies, generating benchmark tickets | `ai/generation/`, `ai/benchmark/` | Apache-2.0 (Qwen2.5-7B-Instruct) |
| `llama3.1:8b` (Ollama) | LLM judge, LLM groundedness check | `ai/judge/`, `ai/grounding/llm_check.py` | Llama 3.1 Community License |
| EasyOCR | Text from screenshot attachments | `ai/ocr/` | Apache-2.0 |

No model weights are stored in the repository; they are downloaded on first use.

**To check before release (Llama 3.1 licence).** The committed confidence model
(`ai/confidence_model/artifacts/confidence-v1-judge.joblib`) is trained on labels produced by
`llama3.1:8b`. The Llama 3.1 Community License places conditions on distributing a model
trained with Llama outputs (including naming), and asks for "Built with Llama" attribution.
The authors should read the licence and decide whether to rename that artifact, add the
attribution, or retrain on human labels only (which the project plans to do anyway).

## Credentials and personal data

The repository holds no real credentials: `.env` files are ignored, CI runs `gitleaks` on
every push, and the full history was scanned in Week 11
([report chapter 8](report/08-security-and-responsible-ai.md)). The demo passwords in
`backend/app/scripts/seed_demo_users.py` (`Demo@123`) and the development database login in
`.env.example` are for local use only. Tickets are synthetic; outside reviewers appear only
as pseudonyms, and their names stay outside the repository.
