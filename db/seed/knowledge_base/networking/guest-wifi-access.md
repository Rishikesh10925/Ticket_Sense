# Requesting Guest Wi-Fi Access

**Department:** Networking

## Issue
A visitor, contractor, or vendor needs temporary internet access without
being placed on the corporate network.

## Resolution
1. Confirm the requester is an employee sponsoring the guest — guest access
   requests must come from staff, not be self-requested by visitors.
2. Issue a guest credential (or day-pass code, depending on site setup) that
   expires automatically — do not issue credentials with no expiry.
3. Guest network is isolated from internal resources by design; if a visitor
   needs access to internal systems, that's a different, more restrictive
   request requiring additional approval — do not put a guest on the
   corporate SSID to work around this.
4. Log the sponsoring employee and expected duration in the ticket for
   audit purposes.

## Notes
If a guest reports the network is "too slow," this is expected — guest Wi-Fi
is intentionally bandwidth-limited relative to the corporate network.
